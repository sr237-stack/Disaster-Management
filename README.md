# Disaster-Management
An academic project that simulates a disaster monitoring and early warning system. It demonstrates how environmental sensor readings can be processed to calculate hazard levels and generate emergency alerts.


#Objectives
1.Simulate environmental sensor data collection.
2.Calculate hazard indices using weighted formulas.
3.Classify disaster risk into Normal, Moderate, High and Critical levels.
4.Simulate an emergency warning siren.
5.Maintain and retrieve incident records using binary file handling.
6.Demonstrate important C++ programming concepts.

#Main Features
1.Sensor station management.
2.Hazard index calculation.
3.Telemetry buffering and averaging.
4.Sensor data comparison and combination.
5.Polymorphic sensor devices.
6.Solar power and LoRa transmission simulation.
7.Risk classification and warning generation.
8.Incident sorting and binary file storage.
